## Что за проект

**Personal Tree** — eco-tech платформа для озеленения Алматы. Пользователь выбирает вид дерева в каталоге и оформляет заказ. Исполнитель реально сажает дерево и подтверждает посадку (фото + координаты). После этого пользователь отслеживает своё дерево в «Моём лесу» и на карте.

Источники:
- Презентация: `/Users/1n8e_/Downloads/Personal_Tree_without_last_slide.pdf.pdf` (11 слайдов: проблема, опрос, бизнес-модель, unit-экономика 6 000 ₸ за дерево, стартовый бюджет 270 000 ₸).
- **ТЗ на прототип** — прислал пользователь в чате. Это главный источник требований, кратко:
  - Экраны: Главная, Каталог (Tree Shop), Покупка дерева (с выбором количества), Мой лес, Карта Алматы, Профиль (история заказов, достижения).
  - Функции: регистрация/вход, каталог, покупка виртуального дерева, оплата **на следующем этапе**, профиль, карта посадок, статусы дерева, достижения и эко-баллы.
  - Админка: виды деревьев (CRUD), заказы, внесение посадок, загрузка фото, смена статусов, статистика.
  - Стиль: зелёный, белый, светло-бежевый; минимализм; mobile-first.
  - Этапы: 1) UI/UX-прототип → 2) MVP (регистрация, каталог, профиль, заказы) → 3) оплата, карта, отслеживание, админка.
  - Путь для демонстрации: регистрация → выбор дерева → заказ → подтверждение посадки → отслеживание.
  - **Жёсткое правило:** данные о реальной посадке появляются только после подтверждения ответственным исполнителем.

## Принятые решения (подробнее в плане)

- Модель — **покупка из каталога** по ТЗ. Накопительные взносы из презентации отложены на после MVP.
- Стек: Flutter 3.x, Riverpod, go_router (`StatefulShellRoute`, 5 табов), freezed/json_serializable, **Supabase** (Auth, Postgres, Storage, RLS), `flutter_map` + OSM, админка на **Flutter Web**.
- Монорепо: `apps/mobile`, `apps/admin`, `packages/core`, `packages/ui_kit`.
- Статусы дерева: `awaiting_planting` → `planted` → `monitoring`. Перевести в `planted` или `monitoring` может только роль `planter`/`admin`, обязательно с фото и геоточкой (RLS).
- Роли: `user`, `planter`, `admin`.
- Код дерева: `PT-ALM-000123`. Одно дерево создаётся на каждую единицу в заказе.
- Эко-баллы и бейджи начисляются **после подтверждённой посадки**, а не при заказе.
- Цвета: зелёный `#2F5D3A`, белый, бежевый `#F4EFE6`.
